🚀 regitlab 使用指南

版本 v0.2.8 最后更新：2026 年 7 月

regitlab 是面向 cscec GitLab/DCS 环境的 Chrome 扩展，提供分支快速选择、Pull Request 自动化、一键部署流水线、灰度用户信息获取与 AI 日报生成等协同工具。安装后建议将扩展固定到工具栏。

支持的域名：插件在以下域名下工作—— https://devops.cscec.com/*（GitLab 主站）、 https://dcs-uat-gray.cscec.com/*、 https://dcs-uat.cscec.com/*、 https://dcs-pre.cscec.com/*、 https://dcs.cscec.com/*（DCS 系列）； 「sync local.user」功能还会在 http://localhost/* 与 http://127.0.0.1/* 下注入本地存储。

1. 初始配置

点击插件弹窗右上角 ⚙️ 齿轮进入设置页面，按需配置以下分组（均可选）。

1.1 快捷选择分支映射

以 JSON 格式自定义「快捷值 → 目标分支」映射，在 GitLab 分支选择时输入快捷值即可跳转。推荐用数字映射 release 各月备份分支，用 a/b/c/d 映射 dev、stable 等主分支。

{"8":"release-20260804","9":"release-20260903","10":"release-20261009","a":"dev","d":"stable"}

1.2 自定义快捷跳转

添加常用链接按钮，显示在插件弹窗顶部，便于快速跳转到灰度、GitLab 等常用页面。输入按钮名称（如「灰度」）和跳转链接，点击「+ 添加跳转按钮」即可。

1.3 显示设置

可开启两个开关：

  • 仅展示自己的提交：在提交记录相关页面只看到自己的提交。
  • 过滤已合并节点记录：过滤 merge 节点记录。
注意：开启「仅展示自己的提交」前，请先在「AI 日报配置」中填写正确的 GitLab 邮箱，否则无法查询提交记录。

1.4 GitLab 配置

清空我的分支排除分支：使用「🗑 清空我的分支」时，填在此处的分支不会被清除。规则：英文逗号分隔，最多 1000 字。

1.5 AI 日报配置

  • GitLab 邮箱（必填）：用于查询提交记录；邮箱不存在则无法查询，也无法配合「仅展示自己的提交」。
  • 常用项目路径：Group/Project 格式，如 cip-economic/cost-react-1。
  • 提交记录分支：查询提交记录所用分支，如 uat（可不填，则用默认分支）。
  • API Key：调用 AI 生成日报的密钥（可不填，则仅展示提交记录）。
  • 日报生成 Prompt 模板：控制生成格式与风格，最多 200 字；会自动拼接提交记录，无需在模板里重复写（可不填，则用默认提示词）。

1.6 编辑器配置

配置编辑器类型（如 cursor、vscode）与开发项目路径，用于获取灰度用户信息后自动打开编辑器到指定文件与行号。

路径填写差异：Mac 需移除开头的斜杠，Win 不做处理。
Win 示例：D:/project/common-react/src/app.tsx:454:0
Mac 示例：Users/username/project/common-react/src/app.tsx:454:0
建议不配置：不配置时仅复制用户信息到剪贴板，不会自动打开编辑器。

2. 主要功能

2.1 部署流水线

在 GitLab 项目页面，通过插件弹窗「🏗️ 部署流水线」面板快速触发部署。可先在「自定义部署分支」输入框手动输入分支，或点击下方内置预设分支快速填入。

项目可用环境
成本GRAY UAT
⚠️ 警告：开发不要轻易部署！触发前请确认分支与环境正确。

2.2 分支快速选择

在 GitLab 项目页面的分支选择下拉框中，输入你在「快捷选择分支映射」中配置的快捷值，即可快速跳转到对应分支。流水线手动部署时可借此快速返回 dev、uat、stable-uat、stable 等分支（原接口较慢且通常失败 2-3 次，此功能可加速）。

2.3 创建 / 接受 Pull Request

在 GitLab Workflow 面板中：

  • ✨ 创建 Pull Request：快速创建 PR 并自动填充相关信息。
  • ✅ 接受 Pull Request：简化接受流程，快速合并。

2.4 生成本周 / 上周日报

点击「📅 本周日报」或「⏮ 上周日报」，会根据配置的邮箱与项目路径自动查询提交记录并展示；若已配置 API Key 与提示词，会进一步调用 AI 生成日报内容，支持一键复制。

2.5 生成 commit 文本

在 GitLab 缺陷抽屉页面，点击「📝 生成commit文本」，插件会读取页面中的版本号、缺陷号、类型（bugfix/feat）、用户 ID、关联需求与缺陷内容，自动生成规范的 commit 文本。非缺陷抽屉页面会提示「无法获取提交文本」。

2.6 清空我的分支

点击「🗑 清空我的分支」可批量清除自己名下的分支，已在「GitLab 配置」中排除的分支不会被清除。

2.7 获取灰度用户信息（$udp.getUser）

在灰度环境页面（DCS-UAT-GRAY），点击「🔍 $udp.getUser」可一键获取当前灰度用户信息并复制到剪贴板；若已配置编辑器，还会自动打开对应编辑器到指定文件与行号。

2.8 同步用户信息到本地（sync local.user）

先在灰度环境页面点击「🔍 $udp.getUser」复制用户信息，再打开需要联调的 http://localhost 页面，在插件弹窗中点击「💾 sync local.user」，即可将剪贴板中的用户信息注入当前页 LocalStorage（键名 UDP_DEV_USER），便于本地使用与灰度一致的登录态。

2.9 DCS 菜单搜索自动聚焦

在 DCS 系列页面（dcs-uat-gray / dcs-uat / dcs-pre / dcs），打开菜单搜索时插件会自动聚焦「请输入菜单名称」输入框，免去手动点击即可输入搜索。

4. 使用场景

  • 快速创建和接受 Pull Request
  • 查看个人提交记录，生成本周 / 上周日报
  • 在缺陷抽屉页面一键生成规范 commit 文本
  • 快速切换 GitLab 分支（自定义快捷值映射）
  • 一键触发部署流水线（前端 10 + 后端 2，覆盖 GRAY/UAT/PRE/ZGY）
  • 一键获取灰度用户信息并打开编辑器，或同步到 localhost 用于本地联调

5. 注意事项

  • 所有配置数据均存储在浏览器本地，不会上传到任何服务器。
  • 使用 AI 功能时，提交记录会发送到 AI 服务，请妥善保管 API Key。
  • 卸载插件时，本地存储的配置数据会被清除。
  • 部署流水线触发前请二次确认分支与环境，避免误部署。

6. 常见问题

插件无法正常工作？ 请确保访问的是支持的域名（见顶部说明），并已在设置中正确配置邮箱和项目路径。
日报生成功能无法使用？ 请检查是否已正确配置 API Key 与 GitLab 邮箱，并确保网络连接正常；未配置 API Key 时仅展示提交记录。
「生成commit文本」提示无法获取？ 该功能仅在 GitLab 缺陷抽屉页面可用，需页面中存在缺陷信息（版本号、缺陷号、用户 ID 等）。
「sync local.user」提示剪切板为空？ 需先在灰度环境（dcs-uat-gray）页面点击「🔍 $udp.getUser」复制用户信息，再在 localhost 标签页打开插件点击「💾 sync local.user」。
如何清除所有配置？ 可在设置页面手动删除各项配置，或卸载插件后重新安装。
